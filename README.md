**Recipe Card – Project Documentation**
Project Name:
Interactive Recipe Card with Animations and Interactivity

**Description:**
This project is a beautiful, interactive recipe card for displaying recipes like "Vanilla Ice Cream" .
It is designed with clean layouts, smooth CSS animations, and basic JavaScript to add interactivity. 
The recipe card is fully responsive and looks great on mobile, tablet, and desktop devices.

**Features:**
Clean and modern recipe card layout

Toggle buttons to show/hide Ingredients and Steps

Smooth hover effects and transitions

Animated progress bar as steps progress

Cooking timer starts when clicking “Start Cooking”

Step-by-step highlighting with a Next button

Fully responsive design with media queries

Print-friendly layout for downloading or printing the recipe

**Files Included:**
index.html – Main webpage with the recipe layout and structure

style.css – Styling for layout, colors, animations, buttons, and responsiveness

script.js – JavaScript file handling interactivity like toggling sections, cooking steps progression, progress bar updates, and timer

images/ – Folder for images (Example: ice cream, cake)

**Technologies Used:**
HTML5

CSS3 (with animations, gradients, and transitions)

JavaScript (basic DOM manipulation and event handling)

Google Fonts (for aesthetic typography)

**How to Run:**
Download the project folder to your local machine.

Open the index.html file in any web browser.

The recipe card will be displayed with full styling and interactivity.

**How to Use:**
Click “**Show Ingredients**” to view or hide the ingredients list.

Click “**Show Steps**” to view or hide the preparation steps.

Click “**Start Cooking**” to start following the steps. The first step gets highlighted, and the timer starts.

Click “**Next**” to move to the next step. The progress bar updates as you go.

The timer keeps running until all steps are completed.

To print the recipe, use the browser’s print option (Ctrl + P), which automatically applies a print-friendly layout.

**Customization:**
You can replace the image URL with any recipe image you prefer.

Change the text in the Ingredients and Steps sections to create different recipes like Brownies, Pizza, Pasta, etc.

Modify colors, fonts, and backgrounds easily from style.css to match your desired aesthetic.
